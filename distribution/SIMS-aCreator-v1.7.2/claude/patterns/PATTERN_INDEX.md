# Pattern Library Index v1.2

Patternは記事の書式テンプレートではなく、検索意図に応じた設計・品質判定ルールである。

## ロード順序
1. `PATTERN_MANIFEST.json`
2. `PATTERN_ROUTING.md`
3. Primary Pattern
4. 必要なSecondary Pattern
5. `PATTERN_COMPOSER_RULES.md`

## 登録Pattern
- `HOWTO` — HowTo
- `TROUBLESHOOTING` — Troubleshooting
- `COMPARISON` — Comparison
- `BUYING_GUIDE` — Buying Guide
- `DEFINITION` — Definition
- `REVIEW` — Review
- `LOCAL_GUIDE` — Local Guide
- `SEASONAL` — Seasonal / Freshness

## 補助Pattern
- `SECTION_DEPTH_WEIGHTING` — 見出し重要度に応じた解説量制御
- `MULTI_CONCEPT_RELATIONSHIP` — 3つ以上の関連概念を比較表・関係図で整理

- `copy-template-pattern.md` — コピー可能な設定・雛形・チェックリストを完成形で提示。
- `citation-candidate-pattern.md` — AI Overview / Featured Snippet引用候補の自己診断。
