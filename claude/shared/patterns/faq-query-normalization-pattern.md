# QA-004 FAQ検索疑問文正規化

## 目的
FAQを本文の言い換えではなく、検索者が実際に入力・発話しやすい疑問文へ変換し、残存不安を直接解消する。

## 必須ルール
1. 質問文は症状・場面・目的が分かる自然な日本語にする。
2. 製品内用語より、読者が観察する状態を優先する。
3. 複数の似た機能・概念を一問で混同しない。必要なら状態別に分けて説明する。
4. 回答は本文のEvidence Boundaryを超えず、新事実を無根拠に追加しない。
5. FAQ数・番号・本文中の参照先を最終出力とJSONで同期する。

## 推奨例
- × 閉じても再生されるのは？
- ○ YouTubeの画面を離れても再生が続くのはなぜですか？

## Validation
質問の自然さ、検索意図一致、概念分離、Evidence整合を確認し、不一致はVAL-FAQ-QUERY-001とする。
