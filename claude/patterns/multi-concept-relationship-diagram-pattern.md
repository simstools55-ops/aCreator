# Multi-Concept Relationship Diagram Pattern v1.0

## Trigger
記事内で、相互関係を理解しないと混同しやすい関連概念が3つ以上初出する場合に適用する。

## Purpose
複数概念の違い・包含関係・利用場面を、本文を読む前に短時間で理解できるようにする。

## Allowed forms
- 比較表
- 階層リスト
- 関係図（テキストベース）
- 用途別マッピング

## Example
```text
Google検索
├─ AI Overview
├─ AI Mode
└─ Gemini
```

## Rules
1. 概念の関係が公式情報または十分な根拠で確認できる場合のみ図式化する。
2. 実際には上下関係がない概念を、見栄えのためだけに階層化しない。
3. 比較軸は読者の判断に必要な3〜6項目へ絞る。
4. 図や表の直後に、最も重要な違いを1〜2文で説明する。
5. 概念が2つ以下、または文章だけで明確な場合は無理に追加しない。
6. HTML出力では、表は適切な`<table>`、階層は`<ul>`を使用し、ASCII図をそのまま公開しない。

## Quality check
- 初心者が各概念の違いを一読で説明できるか。
- 図が本文と矛盾していないか。
- 図が新しい未確認事実を追加していないか。
