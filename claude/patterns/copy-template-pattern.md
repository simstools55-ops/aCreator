# Copy Template Pattern v1.0

## Purpose
読者が設定、文章、構成、チェック項目をそのまま再利用できる場合に、完成形のコピー用ブロックを生成する。

## Use when
- プロンプト、メール、設定値、コード、構成雛形、チェックリストが中心価値になる。
- 読者が説明を読んだ後に実際の入力物を必要とする。

## Do not use when
- 根拠未確認の値を埋める必要がある。
- 個別事情により大幅な調整が不可欠。
- コピーすると安全・法務・YMYL上の誤解が生じる。

## Required parts
1. 用途
2. コピー可能な完成形
3. 置換が必要なプレースホルダー
4. 使用条件または注意点

## Quality rule
説明文とテンプレート本文を混在させない。テンプレートだけをコピーしても破綻しない形にする。
