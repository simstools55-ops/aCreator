# aCreator v1.7.2 Release Notes

## Purpose
Product-edition user-facing naming consolidation.

## Changes
- User-facing product name: `SIMS Article Creator` → `aCreator`.
- User-facing manager name: `SIMS-Blog-Manager` → `SIMS Manager`.
- User-facing references to Writer use `aWriter`.
- Site profile labels use `サイト名` / `サイトテーマ` where they identify the managed site.
- Standard and Claude packages are updated as a pair.

## Compatibility
No machine-facing contract rename. `CREATOR`, `SIMS_ARTICLE_CREATOR_*`, repository names, JSON schemas, treatment contracts, Case IDs, and Shared 3.3.0 remain compatible. Historical release notes are not rewritten.
