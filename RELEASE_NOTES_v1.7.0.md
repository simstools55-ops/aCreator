# SIMS Article Creator v1.7.0

## Personal Knowledge Separation

This MINOR release makes the standard Article Creator distribution tenant-neutral.

- Replaced real blog-name examples with synthetic values.
- Removed tenant-specific Operational Learning records from embedded Shared snapshots.
- Preserved reusable generalized knowledge, Creator contracts, generation logic, and Shared 3.3.0 compatibility baseline.
- Article Doctor / SBM handoff behavior is unchanged.

No destructive migration of existing operational data is required.
